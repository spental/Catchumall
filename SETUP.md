# Reel Faces Setup

## Upload to GitHub
1. Unzip the package.
2. Upload all files plus the `icons` and `assets` folders to a GitHub repository.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for the site to deploy.

## Change the fish face image
The game always uses this file:

`assets/catch.png`

The provided fish-person character is already in that file. To change the catch later, replace that file with your own image and upload the new version to GitHub using the same filename.

## Install as an app
- **iPhone:** Open in Safari > Share > Add to Home Screen.
- **Android:** Open in Chrome > menu > Install app or Add to Home screen.

## Important
- This game uses browser storage for the high score.
- If you clear browser data, the saved high score will be removed.
